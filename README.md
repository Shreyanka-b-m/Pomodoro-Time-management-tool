# Pomodoro - Time Management Tool ⏱️

A productivity timer based on the Pomodoro Technique, built with React.


## Features:  
  **Three Session Types:**  
   **Pomodoro**: 25-minute focused work  
   **Short Break**: 5-minute rest  
   **Long Break**: 15-minute rest (after 4 Pomodoros)  

  **Timer Controls:**  
   **Start/Pause**: Toggle the timer  
   **Reset**: Restart current session  
   **Skip**: Jump to next session  
   **Edit**: Customize session durations  


## Run this app:
1. Clone the repo:
   git clone https://github.com/Shreyanka-b-m/Pomodoro-Time-management-tool && cd Pomodoro-Time-management-tool
2. Install dependencies:
    npm install
3. Run locally:
    npm run dev
